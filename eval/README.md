# eval/ — corpora, fetchers, dataset cards

**Никакие данные не попадают в git.** `data/` в `.gitignore` с первого коммита;
этот каталог описывает, какие данные нужны, откуда берутся и с какими оговорками.

## Dataset cards

### PAN15 Author Verification (основной корпус фазы 1)

- **Что**: 100 задач на язык (EN/ES/NL/GR): known-документы одного автора + unknown-документ,
  truth = same/different. Баланс 50/50. Тексты ~200–400 слов (неформальный регистр,
  кросс-топиковая постановка — «тяжёлый» вариант задачи).
- **Откуда**: Zenodo, record [3737563](https://zenodo.org/records/3737563); лицензию и
  цитирование смотреть на записи.
- **Как**: `python eval/fetchers/fetch_pan15.py --langs en` → `data/raw/pan15/english/`.
- **Роль в пайплайне**: sanity-check верификатора («ловит ли он same-author пары вообще»),
  калибровка τ, материал для подбора весов фузии. Ожидаемый уровень: это трудная задача,
  топовые системы PAN15 получали заметно ниже AUC 1.0 — наши цифры сравнивать с
  публикациями по PAN, не с synthetic smoke.
- **Оговорки**: known-документ один (~300 слов) → unmasking работает на чанках both sides;
  язык только EN/ES/NL/GR (русского нет).

### PAN14 Author Verification (второй, по надобности)

- Тот же формат, 4 языка × 2 жанра (essays/novels/reviews/articles), записей больше.
  Zenodo record [3716033](https://zenodo.org/records/3716033). Нужен, когда захочется
  показать устойчивость весов фузии на другом корпусе.

### Селебрити-фикстуры (запланировано)

- Твиты публичных персон с Kaggle/HuggingFace. **Только eval-фикстуры** (sanity +
  кластеризация), никогда «персоны». Живой скрейпинг площадок не пишем (ToS);
  готовые датасеты качаем отдельным фетчером, когда дойдём.

### Synthetic smoke corpus

- Генерируется в процессе (`harness.data.synthetic_corpus`): «геномы стиля» → тексты.
  Роль: доказать работоспособность конвейера (fused AUC высокий, shuffled control ≈ 0.5),
  НЕ реалистичный бенчмарк.

## Открытая дыра

**RU-корпус целевого регистра** (короткие неформальные посты многих авторов) — не найден
в готовом виде с внятной лицензией. Кандидаты: публичные дампы, PAN13-аналоги. Это
главное ограничение для RU-ветки калибровки.
