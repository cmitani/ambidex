# Ambidex

**Измерительный харнесс для authorship verification** — набор инструментов, отвечающих на один вопрос
строго и воспроизводимо: *дан корпус текстов известного автора и неизвестный текст — может ли
противник доказать, что их написал один человек?*

Ambidex — исследовательский инструмент в области стилометрической приватности. Внутри: классические и
современные методы верификации авторства (семейство Delta, unmasking по Коппелю, метод самозванцев,
char n-граммы, пунктуационные профили), калибровка порогов по between-author распределениям и
**обучаемая** фузия скоров методов (логистическая регрессия по z-нормализованным скорам — никаких
ручных весов).

> Ambidex только измеряет. Он не переписывает, не генерирует и не маскирует текст. Любая система
> маскировки может быть *оценена* этим харнессом; ни одна не реализована в нём.

## Статус

Фаза 1 (харнесс v0) + калибровка порогов. Методология — `docs/methodology.md`.

## Быстрый старт

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"     # Windows; на POSIX: .venv/bin/python
.venv/Scripts/python -m pytest -q                   # юнит-тесты, только синтетика

# сквозной прогон на синтетическом корпусе (без скачиваний):
.venv/Scripts/python -m harness.cli smoke

# реальные данные: PAN 2015 author verification (Zenodo) и полный прогон:
python eval/fetchers/fetch_pan15.py --langs en
.venv/Scripts/python -m harness.cli verify --pan15 data/raw/pan15/english --lang en --name pan15-en
```

Отчёты (JSON + графики + разбор одного решения) пишутся в `reports/<name>/`.

## Методы

| имя | семейство | примечание |
|---|---|---|
| `burrows_delta` | дистанция по z-оценкам самых частотных слов | классика; вклад каждого слова читаем напрямую |
| `cosine_delta` | косинус по тем же профилям | обычно сильнее Burrows (Evert et al. 2017) |
| `eder_delta` | ранговые веса на \|Δz\| | лучше на коротких текстах |
| `char_ngram` | TF-IDF char 3–5-граммы, косинус | пунктуация, морфология, идиосинкразии |
| `punct_profile` | пунктуационно-ритмический профиль | язык-агностичный канал, декоррелирован от лексики |
| `unmasking` | Koppel & Schler 2004 | кривая распада точности при устранении фич; заточен под verification |
| `impostors` | ранжирование против самозванцев (PAN-style) | ранговая статистика, устойчива к масштабу |

Единая конвенция: **score выше ⇒ «тот же автор» вероятнее**; `NaN` = «метод неприменим»
(например, текст коротковат для unmasking). Сырые скоры методов несравнимы между собой до
z-нормализации (её делает слой фузии).

## Инварианты дизайна

- **Веса выучиваются, а не придумываются.** Фузия — логистическая регрессия поверх
  z-нормализованных скоров, обученная на author-disjoint сплите. Коэффициенты — это и есть «формула»:
  их видно в отчёте, они per-language и пересчитываемы. Интерпретируемость кормит отчёты;
  предсказательная сила — фузию.
- **Пороги из данных.** τ определяется на отрицательном (between-author) распределении скоров при
  целевом FPR, per language и per length bucket — никаких магических констант.
- **Без утечек.** Авторы (и PAN-задачи) не пересекаются между сплитом подбора весов и сплитом оценки.
  Контроль перемешанными метками обязан давать AUC ≈ 0.5, иначе где-то течёт.
- **Всё per-language.** Верификация сравнивает тексты внутри одного языка. Кросс-языковой линкинг —
  отдельная будущая атака, не часть ядра.
- **Детекция ИИ-текста — отдельная ось.** Она отвечает на вопрос «человек или машина», а не «кто»,
  и никогда не подмешивается в авторский скор.

## Данные

Корпуса в репозитории нет. `eval/fetchers/` скачивает публичные исследовательские датасеты,
`eval/README.md` описывает провенанс, лицензии и известные оговорки. Синтетические корпуса
генерируются в процессе для тестов и smoke-прогонов.

## Этика и ограничения

Проект измеряет риск приватности (линковка авторства стилометрией), чтобы этот риск можно было
изучать и снижать. Он не идентифицирует людей, не нацелен на платформы; методы документированы вместе
с режимами отказа: точность верификации резко падает на коротких текстах, неформальных регистрах,
переведённом и парафразированном материале. Результаты на одном корпусе/языке автоматически не
переносятся на другие — поэтому per-language калибровка является частью поставки.
