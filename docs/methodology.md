# Методология Ambidex — фаза 1 + калибровка

## 1. Задача

Authorship **verification** (не attribution): даны корпус известного автора K и текст U;
вопрос — «один ли автор». Всё измерение per-language: сравнение строго внутри одного языка,
кросс-языковость в ядро не заходит.

## 2. Конвейер

```
корпус → (пулинг коротких постов, перемешанно) → пары (positives/negatives,
author-disjoint fit/eval) → 7 методов → z-нормализация → фузия (logistic stacking)
→ τ-калибровка на between-author распределении → отчёты (JSON/графики/текст)
```

Пары строятся двумя путями: из обычного корпуса (`pairs.build_pairs`) и из PAN15-задач
(`pan15.pan15_to_pairs`, сплит по задачам — PAN-аналог author-disjoint правила).

## 3. Методы и конвенции

Все методы: **score выше ⇒ «тот же автор» вероятнее**; `NaN` = «метод неприменим»
(не свидетельство ни туда, ни сюда).

| метод | что меряет | почему в наборе |
|---|---|---|
| `burrows_delta` | средний \|Δz\| по MFW-профилю | классика; его per-word вклад читаем — корм для delta-отчётов |
| `cosine_delta` | косинус по z-профилям | сильный дефолт (Evert et al. 2017) |
| `eder_delta` | ранговые веса на \|Δz\| | лучше на коротких текстах |
| `char_ngram` | TF-IDF char 3–5-граммы, косинус | пунктуация/морфология/идиосинкразии; декоррелирован со словарными каналами |
| `punct_profile` | пунктуация/ритм, z + косинус | язык-агностичный микроканал |
| `unmasking` | наклон кривой точности при устранении фич (Koppel & Schler 2004) | заточен под verification; NaN на коротких текстах — честно |
| `impostors` | доля самозванцев, ранжированных дальше unknown | ранговая статистика — устойчива к масштабу, декоррелирована с сырыми дистанциями |

Z-базис профилей = known + background (не пара сама по себе) — иначе дельты несравнимы
между парами. Background пары гарантированно не содержит её собственных авторов.

## 4. Фузия (вместо ручных весов)

1. **Веса выучиваются, а не назначаются.** Logistic regression поверх z-нормализованных
   скоров; коэффициенты = веса «формулы». Ручные веса по «надёжность+интерпретируемость»
   отвергнуты: интерпретируемость — свойство отчёта, в фузии она портит итог.
2. **Z-нормализация обязательна**: масштабы методов несравнимы (дельта-дистанции vs
   наклоны vs доли [0,1]).
3. **Диверсификация вместо коррелированных клонов**: три дельты коррелируют; выигрыш
   ансамбля дают каналы другого типа (char/punct/unmasking/impostors).
4. **NaN → нейтраль (0 после z)**, количество NaN репортится.
5. **Fit только на author-disjoint сплите**; веса per-language (артефакт отчёта, не константа).

`fusion.explain()` — вклад методов в конкретное решение; `deltas.explain_top_words()` —
какие слова дали дистанцию. Это интерпретируемый слой.

## 5. Калибровка τ

`τ = квантиль (1 − FPR) распределения скоров NEGATIVE-пар` (between-author), по умолчанию
FPR = 5%. Репортится TPR@τ и TPR@FPR (интерполяция ROC). Accuracy не используется:
реальный prior сильно смещён к «разные авторы». Дополнительно: AUC по бакетам длины
unknown-текста — верификация коротких текстов драматически хуже, и это должно быть видно.

## 6. Контроль утечек

- авторы (PAN: задачи) не пересекаются между fit и eval, включая background;
- shuffled-label control: AUC на перемешанных метках ≈ 0.5, иначе где-то течёт;
- каждый прогон пишет `scores_fit.csv` / `scores_eval.csv` — сырые скоры для разбора.

## 7. Известные упрощения

- impostors — упрощённая схема (одностороннее сравнение против среднего профиля
  самозванца; без per-chunk минимумов как у Noecker). Полная версия — при нехватке качества.
- eder_delta — аппроксимация рангового взвешивания stylo линейными весами.
- unmasking — линейная регрессия по кривой точности вместо анализа всей кривой.
- Punct-канал z-скороится по basis = background+known, не по большому внешнему корпусу.

## 8. Атаки фазы 2 (реализовано)

- **Кластеризация** (`attacks/clustering.py`): сплочённость целей (средняя попарная похожесть
  z-профилей) против нуль-распределения, построенного повторными выборками из фона; verdict по
  z-score > 2. Плюс доля пар целей в одном кластере агломеративной кластеризации (k = числу авторов).
- **Кросс-юзер** (`attacks/cross_user.py`): K виртуальных операторов × M персон; персоны =
  независимые авторы (нуль). AUC «same-operator vs different-operator» обязан быть ≈ 0.5;
  attribution-sanity (персона против своего корпуса) обязана быть > 0.5 — иначе скоры не работают.
- **L1-утечка** (`attacks/l1_identification.py`): мультиязычная char-ngram модель; leak = доля
  вероятностной массы на самый сильный иностранный язык. Прокси: настоящий L1-id требует корпусов
  неносителей — открытый вопрос.
- **Абляция контента** (`attacks/ablation.py`): прогоны только на служебных словах / только на
  знаменательных; разница AUC показывает, сколько сигнала было темой.
- **AI-детекторы** (`attacks/detectors.py`): отдельная ось; noop + статистическая эвристика +
  опциональная HF-обёртка (`pip install -e ".[detectors]"`).

Pivot-translation атака (перевод всех выходов в один язык) — не реализована: нужен MT-модельный
слой; помечена как следующая после появления мультиязычных корпусов.

## 9. Бенчмарк фазы 3 (реализовано)

`benchmark/maskers.py`: интерфейс плагина + identity / thesaurus / ollama (один generic-промпт,
никаких стилевых целей). `benchmark/run.py`: таблица «метод × атака → метрика»:
`style_removal_auc` (1.0 = стиль нетронут, 0.5 = уничтожен), `lexical_preservation` (TF-IDF прокси
смысла), `output_cohesion_delta`. Ollama-маскировщик пропускается с причиной, если сервер не поднят.
Semantic-метрика на эмбеддингах (multilingual-e5) — следующее улучшение.
